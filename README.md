ZMK Firmware Documentation for Batoid Ergonomic 43-Key One-Piece Keyboard
1. Hardware Specifications
Main Controller: ProMicro NRF52840 development board. No dedicated PCB is provided; all mechanical switches require manual wiring via flying leads.
Power Supply: The development board supports direct connection to a 3.7V lithium polymer battery.
2. Included Firmware Versions
Two complete ZMK firmware builds are supplied: standard base ZMK firmware and ZMK Studio visual configuration firmware.
3. Functional Features
Connectivity: Dual-mode support for wired USB and Bluetooth wireless.
Multi-device Bluetooth: Able to pair and instantly switch between up to 5 Bluetooth devices.
Key Remapping: Once flashed with ZMK Studio firmware, the keyboard supports visual key customization via the web-based ZMK Studio tool.
